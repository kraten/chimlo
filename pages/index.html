The useful details.

Which agents does Chimlo support?

Chimlo currently watches Codex and Claude Code sessions on your Mac. Their activity, questions, and completion states appear in the notch.

Can Chimlo approve every agent action?

No. Claude Code questions and tool permissions can be handled in Chimlo. Codex approvals remain in Codex, while Chimlo shows the session state and takes you back to it.

Does it use my credentials or estimate usage?

No. Chimlo does not read private tokens, cookies, Keychain items, or fabricate usage from token estimates. If a provider cannot report a value, Chimlo shows it as unavailable.

What does it require?

Chimlo 0.1.0 supports macOS 15 or later. A MacBook notch is the intended home, with a fallback floating island on Macs without one.
